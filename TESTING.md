## User Story Testing


| Target | Expectation | Outcome | Screenshot |
| --- | --- | --- | --- |
| As a user | I want to be able to navigate easily throughout the site | so I won't get lost. | ![screenshot](documentation/features/navigation.jpg) |
| As a user | I would like to create new diary entries with a title, date, and content | so that I can record and reflect on my personal experiences. | ![screenshot](documentation/features/create-entry.jpg) |
| As a user | I would like to choose whether my entry is public or private | so that I can decide what to share and what to keep to myself. | ![screenshot](documentation/features/public.jpg) |
| As a user | I would like to edit my previous entries | so that I can update them when my thoughts or circumstances change. | ![screenshot](documentation/features/edit-entry.jpg) |
| As a user | I would like to delete entries I no longer want | so that I can keep my journal tidy and relevant. | ![screenshot](documentation/features/delete-entry.jpg) |
| As a logged-in user | I would like to view entries written by other users that are marked public | so that I can get inspiration or relate to shared experiences. | ![screenshot](documentation/features/public-entries.jpg) |
